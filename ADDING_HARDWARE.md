# Adding Hardware Targets, Device Packs & Boards Guide

Please refer to the full comprehensive guide in [docs/ADDING_HARDWARE.md](docs/ADDING_HARDWARE.md).

For quick reference:
- Hardware Packs: `data/hardware_packs/` (STMicroelectronics, Espressif, Raspberry Pi, Custom)
- Hardware Wizard: Accessible via **File -> Create Embedded Project...** (`Ctrl+Shift+N`) or **Device -> Configure Hardware Target & Pinmux...**
- MCP Hardware Server: 20+ tools registered in `mcp/embedded_ui_mcp.py` and handled by `DesignerController`.
