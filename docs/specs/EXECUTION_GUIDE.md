# Embedded UI Designer – Execution & Milestone Guide

## Phased Roadmap
- **Phase 1 (Weeks 1–10)**:
  - Week 1–2: Project skeleton, CMake configuration, MainWindow, CanvasView & CanvasScene.
  - Week 3–4: Component hierarchy (Button, Label, Rectangle, etc.), selection handles, PropertiesPanel.
  - Week 5–6: Serialization (.euiproj JSON), Project class, Qt for MCUs generator.
  - Week 7–8: Device profiles, live preview pane, build script templates.
  - Week 9–10: Tests, multi-platform CI, packaging (CPack).
- **Phase 2 (Weeks 11–18)**:
  - µGFX C generator, image quantization, macOS/ARM support.
- **Phase 3 (Weeks 19–24)**:
  - Visual state machine editor, interactive simulation, reusable widget library.
